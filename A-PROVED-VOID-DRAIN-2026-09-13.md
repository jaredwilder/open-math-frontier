## Drain rule

Every atlas node is routed through one of four outcomes:

1. **RESOLVED / already surfaced** — the canonical subject repo already exposes the mathematics with adequate authority boundaries;
2. **PROMOTED** — exact identities were buried in a thin subject home and are made reader-visible;
3. **AUTHORITY COURT** — formal/kernel/computational labels are insufficient without semantic inspection;
4. **QUARANTINE / not theorem publication** — route prose, protocol claims, empirical science, or other material that should not be emitted as a pure-math theorem merely because the atlas says `A_proved`.

Historical novelty remains a later court.

## Formalizer firewall

The canonical formalizer audit is deliberately stricter than the atlas tier. It reports:

- 939 receipts;
- 442 with exit code 0;
- 213 passing the full kernel gate;
- 161 after removing already-published topics / retry duplicates;
- roughly 95 carrying real mathematical content;
- 367 distinct clean declaration names across the 213.

The full gate requires `KERNEL_CHECKED`, exit code 0, acceptable axiom footprint, per-declaration cleanliness, zero errors, and direct source inspection for `sorry`, declared axioms, and `native_decide`.

It also contains the crucial semantic negative control: a kernel-clean theorem can still be mathematically contentless if a name such as `RiemannHyp` is merely a bound proposition. Therefore **kernel cleanliness is necessary evidence, not semantic theorem identity**.

## Publication invariant

> **Forensic repositories discover; subject repositories own. Truth, scope, authority, novelty, and publication surface remain separate fields.**

A theorem loses novelty if prior art is found; it does not lose mathematical existence. A route label does not become a theorem because an atlas tier calls it proved. A formal declaration does not become meaningful because its kernel footprint is clean. This drain preserves those distinctions while getting the real mathematics into daylight.
