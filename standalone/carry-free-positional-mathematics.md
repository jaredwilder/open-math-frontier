## 1. Sharp bounded-residue zero detection — `CF-01`

**Source status:** `CLOSED_PROVED`.

Let `r=(r_0,...,r_{m-1})∈Z^m`, `m≥2`, with `|r_j|≤A`. Then

\[
\Phi_B(r)=0\Longrightarrow r=0
\]

for every such `r` **if and only if**

\[
\boxed{B>A}.
\]

**Proof.** Let `t` be the least nonzero coordinate. Divide the relation by `B^t` and reduce modulo `B`; then `B|r_t`. If `0<|r_t|<B`, impossible. Sharpness for `B≤A` is the two-coordinate relation

\[
(-B,1,0,\ldots,0).
\]

Source novelty boundary: elementary/classical arithmetic; rediscovered and sharpened inside the campaign; historical novelty not claimed.

## 2. Sharp injectivity on a balanced integer cube — `CF-02`

**Source status:** `CLOSED_PROVED`.

For `m≥2`, `Phi_B` is injective on

\[
[-A,A]^m\cap\mathbb Z^m
\]

if and only if

\[
\boxed{B>2A}.
\]

Thus the least integer base is `2A+1`.

**Proof.** A collision `Phi_B(x)=Phi_B(y)` is a zero relation for `x-y∈[-2A,2A]^m`, so the previous theorem applies. Conversely, if `B≤2A`, two cube points can be chosen whose difference is `(-B,1,0,...)`.

Source novelty boundary: classical balanced positional representation.

## 3. Carry-lattice kernel generation — `CF-03`

**Source status:** `CLOSED_PROVED`.

The integer kernel of

\[

\[
\boxed{g_j=B e_j-e_{j+1}},\qquad j=0,\ldots,m-2.

**Proof core.** For a kernel vector, the least current coordinate must be divisible by `B`. Subtract the corresponding integer multiple of `g_j` and eliminate coordinates successively.

This completely describes every positional collision as an integer combination of local carries.

## 4. Relation localization by a sharp no-carry threshold — `CF-04`

**Source status:** `CLOSED_PROVED`.

Let `a=(a_1,...,a_n)` be integer coefficients, let `D` be a digit alphabet, and define

\[
M=\max\left\{\left|\sum_\ell a_\ell d_\ell\right|:d_\ell\in D\right\}.

Whenever `B>M`, a global encoded relation

\[
\sum_\ell a_\ell x_\ell=0

**Proof core.** The global relation is `Phi_B` applied to the coordinate-residue vector. Every residue digit has magnitude at most `M`, so the sharp zero-detection theorem forces every coordinate residue to vanish.

## 5. Integer-root divisibility threshold — `CF-05`

**Source status:** `CLOSED_PROVED`.

For the class of all nonzero integer polynomials whose nonzero coefficients have absolute value at most `C`, evaluation at a positive integer `B` is guaranteed nonzero for every polynomial in the class if and only if

\[
\boxed{B>C}.
\]

**Proof.** Factor out the smallest power of `X`. If `B` is a root of what remains, the integer-root divisibility argument gives `B` dividing its nonzero constant term, impossible when `B>C`. Sharpness for `B≤C` is `P(X)=X-B`.

Source novelty boundary: elementary consequence of the integer-root principle; explicitly *not* claimed historically novel.

## 9. No unbounded additive embedding `Z^m -> Z` — `ALG-01`
