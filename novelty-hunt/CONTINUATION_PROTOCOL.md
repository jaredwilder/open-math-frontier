# Continuation Protocol — Recover the Novelty Hunt After Context Loss

This file is written for a future AI/session with **zero conversational memory**.

## 1. Read in this order

1. `README.md`
2. `STATE.json`
3. `BOARD.md`
4. `CANONICAL_LEDGER.md` **in full**
5. Then inspect the public repositories linked by the ledger.

Do not substitute a summary for the full ledger when doing a new pass.

## 2. Mission

Mine `github.com/jaredwilder` for the largest defensible mathematical novelty and publication headlines. The program is cumulative and adversarial against *underclaiming*.

The objective is **not** to prove that results are unimportant. Prior art is used to establish the baseline and identify Jared Wilder's exact delta: new theorem, bound, range, classification, proof, formalization, computation, bridge, obstruction, equality case, or conceptual coordinate.

## 3. Claim discipline

- Distinguish `READY`, `PAPER`, `COMPUTATIONAL PAPER`, `SEAL`, and `MINE`.
- Never promote a bounded computation to an infinite theorem.
- Never demote a valid child theorem merely because the famous parent problem is open.
- Separate mathematical validity from historical priority.
- For computational results, demand reproducible verifier/certificate evidence.
- For formal results, inspect the actual theorem statement and axiom footprint; a clean kernel gate does not by itself prove semantic relevance.
- Preserve corrections and negative results, but do not let them dominate a novelty-ranking pass.

## 4. Sweep method

Each new pass should be genuinely orthogonal to the preceding ones. Good pass lenses include:

- repo-by-repo theorem extraction;
- archive / tarball / receipt recovery;
- formal theorem scope audit;
- equality-case hunt;
- generalization beyond the parent problem;
- exact finite-to-infinite transfer hunt;
- cross-repository bridge hunt;
- literature court for the strongest newly surfaced deltas.

When a result survives, append it to `CANONICAL_LEDGER.md` and update `BOARD.md`. **Do not create a forest of pass files.**

## 5. Current non-negotiable state

- `SATURATION = false`.

- Integral-octagon `ḋ(2,8)>30000` is a ready theorem result.

- Diagonal Ramsey contains an unconditional `o(n)` corridor transfer theorem.
- Do not resurrect already-corrected false/retracted claims as headlines.

## 6. Finish condition

A novelty-hunt pass is complete only when it reports:

- newly promoted headlines;
- newly demoted/cleared items where useful;
- exact evidence and remaining seals;
- whether the ranked board changed;
- whether saturation remains false.

The default expectation is that **more is buried** until repeated independent passes cease moving the board.
